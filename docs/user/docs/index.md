# Welcome to Chromaticity

Chromaticity is a real-time audio-reactive VJ performance and shader authoring engine built for live shows, club booths, and livestreams.

## Getting Started in 60 Seconds

- **Choose your audio input** in [Settings](settings-reference.md) — Chromaticity hot-swaps audio inputs live without interrupting stage output.
- **Launch a scene** from **Library** or press `⌘K` / `Ctrl+K` to jump straight to any scene or tool.
- **Perform live** with **Scene Controls**, **Meta Controls**, and 8 instant **Snap** slots (`1`–`8`).
- **Open your stage output** with **GO LIVE** in the top bar, or toggle the **STAGE** monitor dock from any workspace.

## Essential Booth Hotkeys

- `?` — Toggle the full Hotkey Reference overlay
- `⌘K` / `Ctrl+K` — Open the Command Palette
- `B` — Toggle instant Blackout
- `S` (hold) — Momentary Strobe
- `1`–`8` — Recall Snap slots on Perform
- `Space` — Play or pause the active Playlist
