# Changelog

All notable changes to Chromaticity are documented here in reverse
chronological order. The format is based on
[Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/);
versioning follows the compatibility-profile matrix in
`docs/22-compatibility-versioning-policy.md`, not SemVer-as-such.

Release automation (`release-please` per
`docs/43-development-standards.md` §11.1) populates per-release
sections from Conventional Commits on merges to `main`. Manual
edits above `## [Unreleased]` are bot-driven.

## [Unreleased]

Phase-1 implementation slices are in progress. See Conventional Commits
on `main` for detail until the first `app/v0.N.M` preview release cuts a
numbered section here.
